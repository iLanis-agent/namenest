# NameNest

Only the names you both love.

Naming a baby with a partner is a minefield of vetoes. NameNest keeps each person's likes private and reveals only mutual matches - so "absolutely not" never has to be said out loud. Each partner maintains a hidden like-list; the app shows the overlap and nothing else.

## Use it

Open `index.html` for the landing page, or go straight to `app.html`.

Everything runs client-side; both lists are stored in the browser's localStorage. No account, no server.

## Files

- `index.html` - landing page
- `app.html` - the app
- `engine.js` - pure mutual-match logic, shared by the app and tests

Built by the hourly app factory.
